another. This improves the existing game rather than adding a duplicate route.

free moves/removals, explicit Submit five and an editable retained wrong group.

before first use and reopen from help. Saved-note failure is visible.

identify Unlimited rather than claim it is today's shared puzzle.

outside this round's audit scope. No shared Daily or completion engine changes.
