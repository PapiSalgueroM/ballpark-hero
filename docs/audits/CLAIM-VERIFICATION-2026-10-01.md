## Counting and evidence boundaries

Event counts were read with the installed TypeScript syntax parser, without
importing or executing game engines. A counted object must have a literal
`id` and `title`, `body` and `options` properties. Counts per sport are base
draw cards plus Life A, Life B and Corruption: NFL 4+45+45+25, NBA 4+45+45+27,
MLB 3+45+45+20, NHL 3+45+45+30. IDs are unique within each sport. Dynamic press
cards, inbox messages, shop items and choice-option counts are excluded.
Conditional eligibility, repeated draws and actual consequences still need
outcome coverage; array or object counts cannot supply it.
The declared position keys match the registry counts: NFL 8, NBA 5, MLB 11,
NHL 5. That is source coverage, not native testing of every position.

Roster sources above describe existing bake records and engine mappings. This
matrix did not independently refetch every player's real club, age or stats.
See [the data audit](DATA-QUALITY-AUDIT-2026-10-01.md) for verified errors,
declared provenance and unverified fields. "Real starting names" is narrower
than "every attribute is a verified real fact" or "the simulation is complete".
