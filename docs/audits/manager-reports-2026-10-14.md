Only the created club's private league view aliases the real slot to its name. Sort the finished own table under its original identities and saved tiebreaks before translating the created row back to the real slot for exchange.

When staying, update the created club's stored league from the slot's earned membership and keep its replacement slot across later summers. Fresh starts and reloads register saved membership before calculating the custom definition and objectives. When departing in summer or midseason, the real slot becomes visible again and captured European fields replace the departed created name with its real slot. `initUclGroup` uses the active created club's league for domestic-opponent exclusion only in modern configured pairs.
