## What changes for a player

Footle presents each revealed guess as eight labeled cards. Phone players can
read the actual nation, club, goals, assists, position, kit number, age and value
without panning an 880px table. Every card retains the existing comparison
engine's value and exact, close, incorrect or unknown state. Higher and lower
arrows also have words. Unknown values do not gain a comparison.

Numbered 44px controls revisit existing guesses. A new guess selects its own
clues, while Back to search restores the search input. The finite card entrance
has a static reduced-motion version. Reopenable instructions explain the cards,
history and completed-run review with a hypothetical example.

A completed five-puzzle run has five review selectors. Each review reconstructs
that round's actual guesses from the saved frozen pool and existing comparator.
A missed puzzle with no guesses says so. Back to run results restores the review
opener. Review attempts no writes to the saved run, Daily result, streak or
completion records. New runs and mode changes close the old local review.

The shared GameBoard, useGame hook, comparison engine and practice-run model are
unchanged. Scoring, eight guesses, target selection and save schemas retain their
existing behavior. No real sports facts, external imagery or paid mechanics were
added.

viewport. The clue desk now requests its first reveal rather than skipping it.
Completed reviews use that same desk-owned reveal and a return control beside
the guessed-player heading. The native driver checks the actual heading and

return control, including the honest zero-guess review.

restart. Reducing the guess count now clears that local selection. The mounted
case completes a fixed same-answer replay, makes new guesses and requires the
latest guess. Its source control removes that reset and must reject the named
replay assertion.

USD clue value for each, retaining the existing result-currency and concealed
answer assertions and the effective wrong-currency control.
