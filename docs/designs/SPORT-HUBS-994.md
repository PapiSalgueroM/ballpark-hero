# Sport destinations, round 994

The six hubs become entrances to a sport's games. Keep the existing catalog
and useful guides, with original fictional arena illustrations, a prominent
play or resume action, career cards, and a searchable game library.

Palette: deep arena navy #0c2030, ice white #f5f8fa, muted steel #c1d2e2,
court amber #ffbc71, grass mint #75e0a3 and ice cyan #97e5ee. Reuse the site's
Space Grotesk headings and Inter body text. Keep reading text in the theme's
existing colors so light mode remains usable. Artwork headers have their own
fixed dark contrast treatment.

The memorable element is the venue. Surround it with a quiet, left-aligned
library. The initial idea of another same-size card grid would repeat the
old hubs, so career cards have a distinct scale and the full arena provides
the sport identity. No autoplay video or decorative infinite animation.
Controls respond immediately to a chosen filter or query; random discovery
only occurs when the user explicitly asks for a game.

```
six sport links
arena: title, actual collection count, play or resume
saved games, when present
library: filters, search, choose a game
careers and managers, followed by quick games
existing sport guides and related links
```

Acceptance: each hub initially links every registered game exactly once in
its catalog. Daily and simulation filters use registry flags. Search and
reset work; empty searches recover; random discovery stays in the visible
set. Saved links stay within their sport and show the existing safe save
description. Phone and desktop controls fit, support keyboard and touch,
and preserve existing records. No change to sports data or saved games.

Artwork uses the built-in image generation tool. Five original empty fictional
venues, no people, club or league marks, sponsors or real-stadium identity.
PNG masters stay in the generation folder; WebP delivery copies are encoded
without changing the composition. College shares the football venue.
