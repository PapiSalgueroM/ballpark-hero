## 1. Which session you are, and the setup that actually works

This file was written from a **claude.ai/code cloud session**. That is the path with GitHub
credentials and no access to Anthony's Windows folder. `CLAUDE.md` has the full table; the short
version is that on this path you commit, `git push -u origin <branch>` and open a draft PR, and
you **never** write a `ROUNDnn_FILES.zip`, a `RUNnn.bat` or a `SHIPnn.bat`, because nothing on
this machine can use them.

A fresh cloud container gives you the clone and nothing else. Three installs, in this order,
and the second and third are the ones people forget:

```
npm install
npm install --no-save playwright
pip3 install fonttools pillow
```

Measured today: `npm install` is the slow one, the other two are quick. Chromium is already at
`/opt/pw-browsers`, so do not run `playwright install`. `pip3 install fonttools pillow` prints a
root user warning; that is normal here and not a failure.

Without the playwright package, every browser harness and `scripts/prerender.mjs` fail on
import. Without fonttools and pillow, `simBrand` fails closed. Neither failure looks like a
missing dependency at first glance, which is why they are written down.

**What this path does not have, and does not need:** Anthony's folder, the CRLF problem (a fresh
clone comes up clean, so a dirty `git status` here means real edits and is worth reading), the
cloud clone revert bug, and the `git checkout` rollback trap. Ordinary git works. `add`,
`commit`, `status`, `push`, `fetch` and `merge-base` were all used today without trouble.

## 5. What landed on 2026-09-16, and the one lesson worth keeping

Full detail is in `docs/PROJECT-STATE.md`, which is the source for all of this. The short
version and why it matters to the next round:

**Three fight games on one engine (620, 625, 627).** `/fight-career`, `/fight-gym` and
`/fight-promoter`. Same fighters, bouts, damage and ageing in all three; what changes is whose
problem it is. This is the owner's "one engine, many sports" instruction done properly, and it
is the shape to copy rather than Round 426, where the same roster refill bug had to be fixed
twice because two engines were two copies of one idea. New `src/lib/careerEngine.ts` is the
shared piece.

**The four live my career games were deliberately NOT migrated onto that engine.** That is
Rounds 621 to 624, one sport per round, each proving byte identical career outcomes on a fixed
seed before and after. Moving four working games at once for no immediate player benefit risks
all four, and the gates cannot tell a silent behaviour change from a correct one.

**The lesson, and it is the reusable one: a game's own harness cannot tell you the game is
registered.** The three fight harnesses were green, the round looked done, and then the full
suite on a complete install found **six real registration gaps**:

- `simInventedNames`: the fighter name bank was unregistered, so nothing was checking generated
  fighters against real athletes. That is the legal rule, not a nicety.
- `simLeaderboardCaps`: all three games could record a completion with **no cap row**, so every
  point earned in them would have been silently discarded.
- `simSitemap`, `simIndexing`, `simHubs` and `simPrerender`: the saved pages predated the games,
  so nothing linked them, nothing indexed them, and What's New dropped their entries.

Adding a game touches the sitewide SEO and scoring machinery, not just the registry. `CLAUDE.md`
has the six step checklist for adding a game; the sixth step (`node scripts/genSearchKeywords.mjs`)
is the one with no npm script and no CI step behind it, so nothing runs it for you.

**The IndexNow floor is exact in both directions on purpose** (`simIndexNow`, 148 to 151). Growth
without raising it is a page nobody fenced. That harness sat red for five rounds once because two
rounds that added a page ran the sitemap check and skipped this one.

**College Grid works.** The new cache row is `ray lewis|miami (fl)|top 10 pick`, verdict
`valid: false` with `unverified` absent, which proves three things at once: the validator ran
rather than timing out, it reached a definite verdict rather than the fail closed retry so no
player lost a guess, and the verdict is factually right (Ray Lewis went 26th in 1996 out of
Miami, per Pro Football Reference and the Pro Football Hall of Fame). The "zero completions in
six hours" reading was a niche game with a low completion rate, not a broken one. Nobody needs
to investigate College Grid.

## 7. Obligations and traps that still apply here

**Landing on main is not publishing.** Both ship paths end the same way: main updates the Lovable
**preview only**, and douknowball.com serves the published snapshot until somebody calls
`deploy_project`. Skipping that is why the live site once served a June build for weeks while
GitHub was current. And deploy only **after** the sync: `get_project.latest_commit_sha` must equal
main's head, or the deploy builds the previous commit and every proof grep passes on nothing.

**Never invoke an edge function yourself.** Each call writes `ai_validation_cache` and spends
players' AI allowance. Use the Supabase MCP for SQL, and `get_edge_function` to read a deployed
function back.

**Columns people get wrong:** `game_completions` has `game` and `created_at`, not `game_slug` and
not `completed_at`.

**Auth logs contain players' personal emails.** If a query pulls them into view, do not copy them
anywhere, including handoffs and commit messages.

**Commit with explicit paths.** `git add <paths>`, never `-A`. Read `git status` before every
commit, and put `&&` between a gate and the commit so a red gate cannot produce a commit.

**Guide copy edits need `node scripts/genSearchKeywords.mjs`,** or `simSiteSearch` section 7 fails
on the guide hash. Editing `src/data/gameContent/` counts.

**The rival names guard scans URLs and code comments too.** The repo is public, so a comment
naming a competitor is exactly as readable as a button naming one. Sponsor names inside league
API paths trip it: cite the host in `src` and keep the full request in `docs/`.

**The invented quote guard reads first person words** ("our", "we") on a line that names a real
player as speech. Rephrase; never weaken the detector.

**`simUclSeasonOne` compares against origin/main's src,** so any other round on the same branch
that changes Club Manager data makes it red. Use `UCL_S1_BASE=HEAD` on a combined branch. This is
worth remembering for Round 619, which edits exactly that file.

**Never run the harness suite while a build is running.** Two harnesses once reported failures
that were just them reading a half written `dist`.

**A killed harness run can leave control directories** (`src/.google-paused-control-*`). Check
`git status` for stray `src/.*-control-*` after any interrupted control run.

**Regenerate one saved page without a full `build:seo`:** `vite build`, then
`PRERENDER_ONLY=/route node scripts/prerender.mjs`, then `node scripts/genSitemap.mjs`, then
`vite build` again. (The `MSYS_NO_PATHCONV=1` prefix the old handoff gives is a Git Bash fix and
is not needed on this path.)
