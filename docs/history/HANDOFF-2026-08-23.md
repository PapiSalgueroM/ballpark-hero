## The lesson that produced three of those rounds

**A check that cannot run is worse than no check, because everyone assumes it is
watching.** The full board with `--browser` had not been run in months. When it was:
29 of 37 browser harnesses passed and all 8 failures were the harnesses, not the site.
Six died on `waitUntil: 'networkidle'`, which on this site can never be reached
(measured: `/` had 6 requests still open, `/records` 10, all Supabase, which hangs
rather than fails; and `useDailyLegend` opens a realtime websocket). Two died launching
WebKit, which cannot be installed here. Fixing them surfaced a third problem, browsers
running the container out of memory on long sweeps, fixed by recycling every 25 routes
the way the prerenderer has since Round 257.

**And: presence is not correctness.** Nine rounds of checks asked whether a canonical
or a description was PRESENT. Presence was true the entire time. The checks count now.

## Traps that will bite a fresh session

- **Never run `git checkout` in the cloud clone.** It is a rollback to `origin/main`,
  which is nineteen rounds behind. It silently deleted six routes once and tsc, the
  build and the sitemap generator all stayed green afterwards.
- **No em dashes or en dashes anywhere.** Code, comments, commits, site copy, messages.
- **The findstr assertion rules** in `docs/SHIP-PIPELINE.md`. Backslashes in file
  arguments, no raw quotes, no cmd operators, no percent signs, ASCII single line.
  An assertion that can never match is worse than none: verify absence assertions
  actually fire against the pre-fix file.
- **`npm run build:seo` ends with a second `vite build`**, because the prerenderer
  writes into dist and would otherwise overwrite the Round 275 asset tags.
- Type gate is `node_modules/.bin/tsc --noEmit -p tsconfig.app.json`.
- The repo permanently shows ~642 modified files. That is pure CRLF. Never commit them.
