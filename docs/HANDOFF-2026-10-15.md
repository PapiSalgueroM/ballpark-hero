## 4. What changed in how releases run

- **A join of the other lane's packets** is the cheapest way to ship a lot: it built and qualified them, the join merges
  the exact qualified commit, binds old proofs to the new tree (env refs defaulting to the original parent, never an
  edited assertion), and proves per merge. BE (10 PRs) and BF (9 PRs) cost about 0.7M tokens each.
- **roundsG.js needs `stage: 'finish'`** for a builder or a join; without it the run ends at once with nothing done.
- **The other lane may merge to main itself** (fc215eaa, its full PR270, while BE was in its gate). Fetch main before
  every push; if it moved, merge it into the release branch and gate again. The BE record asks it to leave merges to
  this lane.
- **A rerun of one line from a lane** must carry the lines it depends on (the hub walk's section D needs the base server
  an earlier rc-V line starts).
