  the release's or the walk's (Release AR, a goal that lost its net when the other side changed a man).
- Deploying right after a push publishes the previous commit. Wait for `latest_commit_sha`.
- The Edit tool turns a typed backslash u escape into the character itself and a doubled one into two backslashes.
  For a dash free test write `String.fromCharCode(0x2013)`.
- `node -e` through Git Bash loses backslashes: write scripts with the Write tool. `MSYS_NO_PATHCONV=1` in front of
  anything whose argument starts with a slash. Stamp the ledger with `date`, never from memory.
- A workflow agent whose own command runs longer than three minutes is restarted from scratch: everything heavy
  goes to a runner; agents poll with short loops and never use background tasks.
- Never `git add -A` here, never edit the root checkout, never push to a branch another worktree has checked out
  without fast forwarding it, never run anything against production from an agent.
