## 6. Traps met this session (each cost time)

- **A words only fix moves a digest.** A fixer reworded one NHL card's result sentence; a recorded digest
  hashes the logged sentence, so the gate went red on 4 of 1,200 saves. A grep for the old text cannot see a
  hash. After any fix pass run the gate's lane lists, not only what the fix touched. Recipe used: bisect on a
  runner (one worktree a commit), prove attribution (the old sentence put back is green against the old
  record), record again on the runner, bring the file back from `files/`.
- **A red band is measured before it is blamed.** `simHalftime` failed once in the gate; three isolated runs on
  the head and three on main (each in its own worktree and its own TMPDIR) were six of six green.
- **The proof of a train is the gate's own lists.** Three browser walks nobody had run turned Release AT's
  gate red; since then every integrator's proof is the lists, and every walk that drives a touched screen.
- **A call I got wrong twice:** `playSaveKeeper` compares against a build from BEFORE the save keeper
  (`fb8d6811`); pointing its base at main makes it red for that reason alone.
- **The host can lag.** After a push, `get_project` showed the old commit for four minutes. Never deploy before
  `latest_commit_sha` is the pushed head.
- **Scheduled wakeups did not fire**; a background shell waiter does (its exit is a notification). A foreground
  sleep is refused.
- **An app restart stops every workflow** and a resume across it is not possible: relaunch fresh; the prompts
  tell each agent to carry on from its branch and notes.
- **A reviewer can stop dead.** After an hour of quiet, list the running agents from the workflow's journal and
  look at their transcript times.
- **Agents overwrite report names on a second chain.** They kept the earlier ones under other names this time;
  give a closing pass its own round label next time.
- **tar on this PC** reads `C:` as a host: use a `/c/...` path and `--force-local`.
