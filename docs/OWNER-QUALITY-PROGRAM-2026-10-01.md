Each verified defect needs URL, game/page, exact reproduction steps, expected
behavior, actual behavior, severity, likely cause and a receipt. Separate live
observations, clean local production browser runs, engine tests and source-only
findings. A failed harness or unreachable service is not automatically a site
defect. Untested flows stay untested. Never fill a Top20 list with suspicions.

The audit inventory includes all requested fields: URL, game name, sport, type,
playability, completeness, data use, daily/evergreen, mobile/save coverage, bugs,
dead controls, missing/placeholder/duplicate content, data errors, console errors,
policy concerns and indexability. The final report includes repair/consolidation/
indexing recommendations, ad/disclosure changes and a pre-submission checklist.
Recommendations are not production changes.
