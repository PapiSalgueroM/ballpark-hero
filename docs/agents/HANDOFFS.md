# Handoffs

A handoff here is three things, all mandatory per round: the commit message
(the full narrative), the board Done entry, and the PROJECT-STATE change log
entry. Cross-lane notes (a diagnosis one lane leaves for the other) go on the
board item itself, the way the Trade Finder recon and the World XI position
data notes already do. Read the other lane Done entries before touching a
subsystem it recently shipped.
