## 6. Environment traps, all hit this night, with the fix

- **Removing a worktree whose `node_modules` is a junction deletes the real `node_modules`.**
  Unlink first: in PowerShell, `[System.IO.Directory]::Delete('<wt>\node_modules', $false)`,
  then `git worktree remove --force <wt>`, then `git worktree prune`. Confirm
  `Get-ChildItem node_modules -Force | Measure-Object` still says about 366. With the binary
  gone, `tsc ... && echo ok` still prints ok: read exit codes, never echoes.
- **Bash's `/tmp` is not node's `/tmp`.** A node script handed `/tmp/x` throws ENOENT while
  the shell chain carries on. Use the session scratchpad by absolute Windows path.
- **A bash heredoc strips backslashes** on this machine. Write scripts with the Write tool.
- **CRLF:** every fresh checkout is CRLF; a harness matching a multi line needle against raw
  source silently finds nothing. Normalise with `.replace(/\r\n/g, '\n')` before matching,
  and make every control refuse to run if its rewrite changed nothing.
- **A node AbortSignal.timeout still pending at exit crashes node on Windows** (libuv
  assertion, exit 127, looks like a broken harness). Own the timer and clear it, and let the
  socket settle before `process.exit`.
- **The Codex lane commits on main** in the same tree while you work. Its label "Round 447"
  collided with this lane's 447. Read the workboard's next number every time.
- **Merge order matters for the huge files**: Club Manager rounds after 462, Conquest rounds
  after 457, Rebuild rounds after 456 and 461, Stock Market after 458 and 453.
