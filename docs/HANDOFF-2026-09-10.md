## 9. Traps hit this session (each cost real time; the fixes are in memory too)

- `$TMPDIR` is EMPTY in the Bash tool here, so `> "$TMPDIR/x.log"` becomes `> /x.log`,
  refused, and the whole command exits 1 before the program runs. A background build "failed"
  having never started. Use the absolute scratchpad path spelled out.
- `PRERENDER_ONLY=/route` gets mangled by MSYS into `C:/Program Files/Git/route`. Prefix
  `MSYS_NO_PATHCONV=1`. And the prerender reads the route list from `dist/sitemap.xml`, so a
  new route needs `genSitemap --routes-only` and a build first; the full `npm run build:seo`
  is simpler.
- `runAllSims.mjs` buffers everything until exit, takes 60 to 90 minutes here, and
  `TaskOutput` blocks time out at 5 to 10 minutes each; keep waiting, check the process is
  alive with `ps`. Do not edit `src` or `scripts` while it runs.
- A harness that renders a component through `react-dom/server` has no Router; the moment
  that component gains a react-router `<Link>`, `useContext` throws. Wrap the render in a bare
  `MemoryRouter` (done in the two Club Manager era harnesses). Grep for `renderToStaticMarkup`
  before adding a `Link` to any card.
- `simLegalPages` section 4 requires every external host in shipped `src` to be named in
  Privacy Section 4. A page that merely LINKS to a new host (wikipedia.org) trips it. Add an
  honest line; do not weaken the check.
- `git commit` commits the whole index. Files staged with `git add` earlier in the session rode
  into what was meant to be a docs only commit. Read `git status` before every commit.
- Lovable's `latest_commit_sha` lags a push by a minute or more; the first `get_project` after a
  push usually shows the previous commit. Never deploy until it matches.
- The adversarial review's dropped findings are unconfirmed, not refuted. Read them.
- The review refuters can be right in the small print too: two Wikipedia pages are one
  publisher, not two.
