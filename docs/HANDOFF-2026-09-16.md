## 5. What each round actually is

**619.** `releasePlayer` puts a man in a free agent pool and leaves a settlement on the wage bill
at half his wage for up to two seasons. `signFreeAgent` is the one deliberate window bypass in the
game and is a new function rather than a weakening of the nine existing window guards. Contracts
that run out send the player to the pool too. Ten harness sections, eight controls.

The section worth knowing about is 9. Two drafts asserted on a percentage (what share of a club's
own seniors would re-sign for nothing) and both put the threshold inside the measured spread: 60
against a measured 43 to 69, then 40 against 13 to 48. At a weak club the squad clusters around
the club's own level, so no single gap is both useful there and tight elsewhere. It now asserts
the binary claim instead: **no club's own best player may ever be signable for nothing.**

**628.** Fight Career already played round by round but every round rendered as the same
paragraph. Now: two condition bars that drain, per round punch bars drawn against the busiest
round of the night, a flash when somebody goes down, a card that pops only when it changes, and
confetti on a win with gold for a stoppage. The bars come from `conditionTrack` in
`src/lib/fightCareer.ts`, deliberately in the lib and not in the render, because a number computed
inside a React render cannot be measured by a harness.

**629.** `scripts/simHarnessAnchors.mjs`. A harness that reads a file under `src/` and searches it
with a multi line string literal must normalise line endings on read. 28 harnesses are in scope
and all comply. Control `ANCHOR_CONTROL=strip`.

## 6. The traps this session actually hit

**A harness that invents its own population will confirm whatever it invented.** This is the one
worth carrying forward. Round 628's drain rate was measured on fighters built straight from
`makeFighter` at tiers 2 to 4, which land 2.9 punches a round. Bouts the game actually produces
land 7.4. Section 6 drew its sample the same wrong way, so the constant and the check agreed with
each other and neither described the game: tsc was zero, the harness passed at 89.5 percent, and
opening the page showed both fighters pinned on the floor after a points decision. Section 6 now
plays real careers through real offers and real camps, and its FIRST assertion is that the sample
looks like the game before it asserts anything about the bars.

**CRLF kills any multi line anchor, invisibly.** This checkout stores `src` CRLF and an anchor
written inside a harness is LF, so a single line anchor matches and a multi line one cannot,
ever. `noretire` and `driftdaily` in `simFightCareer` had never fired since Round 620, so its
sections 2 and 4 were green because their control changed nothing. Same in `simFightGym`
(`noretire`), `simTransferPathRepeat` and `simPollCharacter`. All four are fixed and Round 629
fences it. **74 harnesses already normalise**, so this was new code missing an existing
convention, not a repo wide rot: an early sweep of mine claimed 45 affected harnesses and that
number came from a mis-escaped shell pattern. The real number was four.

**Run every control one at a time, and read its whole output.** Round 619's `nodecay` pointed at
text the source does not contain and refused to run; its `nodedupe` applied cleanly and broke
nothing, because section 5 released one man and asserted his one name appeared once, which is
true of any list built by one push, so the dedup line was never reached. Neither shows up unless
you run the controls individually.

**A worktree has no `node_modules`, and that failure is silent during a control audit.** Any
harness that spawns `ROOT/node_modules/vitest/vitest.mjs` or similar by absolute path cannot run
from one. `simGmReload` and `simPollCharacter` both reported zero failures and no "cannot run"
line, which reads exactly like a dead control; both had applied correctly and then failed to load
vitest, several lines above the counter being grepped. **That nearly went into the record as two
more findings.** Do control audits in a tree with a complete install. Imports resolve by walk up,
so `tsc` and hand written harnesses work and give you false confidence.

**Bash heredocs still eat backslashes on this machine.** A node script written through one turned
`\\n` into a real newline and would not parse. Use the Write tool for anything with escapes. This
is in the repo's own history and I hit it anyway.
